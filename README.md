**Hi, and welcome to Bootloader Code development for ARM Cortex M4, MCU STM32F407** <br/>
 The aim of this repo is to examine key aspect of MCU startup control execution and integrate it to an appl which in this case is done with the help of the repository: <br/>

  https://github.com/PaulRojas-41/ARM_M4_RTOS <br/>
  **1. Datasheets used:** <br/>
  RM0090 <br/>
  DM00037051 <br/>
  DUI0553 - Generic ARM architecture <br/>
  **2. Topics so far covered:** <br/>
  Bootloader initial code <br/>
  Bootloader jump to appl <br/>
  Simple key validation before jump to appl <br/>
  CRC32 validation before jump to appl <br/>
  OTA 1st stage (sketch) <br/> 
  **3.Environment:** <br/>
  STM32CubeIDE
  STMPrg allows user to flash boot and appl code <br/>
  UART CONSOLE
